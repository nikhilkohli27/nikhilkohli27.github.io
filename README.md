# nikhilkohli27.github.io

Personal website for [Nikhil Kohli](https://github.com/nikhilkohli27).

Live at **https://nikhilkohli27.github.io** (after GitHub Pages finishes deploying).

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Audio

Add `assets/audio/weird-fishes.mp3` locally, then commit if you choose to host it on Pages.

## Custom domain

When you own `nikhilkohli.dev`, add a `CNAME` file and configure DNS in GitHub Pages settings.
